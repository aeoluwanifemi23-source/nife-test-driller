# Nife's Test Driller

A self-contained CBT (Computer-Based Test) practice web app for UNILAG courses. Single-file React app (no build step) — everything lives in `index.html`.

## Courses included
- GST 112 — Nigerian Peoples & Culture (375 questions)
- MTH 102 — Calculus (141 questions)
- PHY 104 — Vibrations, Waves & Optics (362 questions)
- MTH 103 — Mechanics (134 questions)
- PHY 102 — General Physics II (625 questions)
- STA 121 — Introductory Statistics (287 questions)

## Running locally
Just open `index.html` in a browser — no build, no server required.

## Deployment
This is a static site (single HTML file), so it deploys as-is to GitHub Pages, Vercel, Netlify, or any static host.
